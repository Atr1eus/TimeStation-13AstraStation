## 游戏介绍

宇宙中有一列时空列车，时空列车从现在启程前往过去或未来，令的无数人趋之若鹜，其中掺杂普通人、凡人、不法分子、士兵甚至一些“特殊”的人。 作为一名“时空列车”的检票员，你的职责是严格审查旅客们的登车资格，你需要发现车票与申请表中与客人描述的不符之处并决定旅客是否通行（放行批准）。除此之外，你需要赚取足够的“回忆磁带”，以应对列车日常所需。

**前往Release即可下载打包好的可游玩版本。**

## 操作说明

1. **查看证件**
   当乘车人走到窗口时，会将车票以及申请表递给你。
   ·鼠标点击拖动可查看相关证件信息。
2. **列表选择**
   ·当回合开始时，玩家需要在一系列申请人中选择要检查证件并决定是否通行的人。
3. **检查**
   乘车人会为了通行，如实、伪装、求情等方式言明自己的故事。
   仔细观看乘车人口中的故事，并分辨车票与申请表上的信息：
   ·姓名、目的时间、发行方
   ·姓名、年龄、出行理由、行李列表
4. **对话**
   乘车人会讲出自己的故事，玩家可根据预设的选项决定不同的对话走向
   ·点击对话选项走向不同的剧情
5. **决定是否放行**
   根据比对的信息和对话，玩家可决定该乘车人是否通行
   ·在“同意乘车”与“拒绝乘车”中选择一个点击，决定申请人是否通行
6. **升级**
   玩家需要赚取列车每回合所需要的“磁带”，以维护列车的正常行进。
   时空列车初始权限有限。随着游戏的进行，玩家可消耗磁带增加可选择的乘车人以及乘车席位。
   ·根据放行情况获得一定量的“磁带”，并达到每回合最低要求
   ·消耗一定量的“磁带”可对列车进行升级，解锁更多的乘车人和席位
7. **下一位**
   ·当前申请人离开（无论同意或拒绝）后，点击窗口上的“下一位” 按钮再次打开列表选择下一位申请人。
8. **休息**
   玩家每回合能选择的申请人和座位均有限，需要进行休息回合才能进行更多的回合。
   ·当玩家无更多空置座位或无更多申请人时，出现“休息”按钮
   ·点击“休息”按钮，进入休息室场景
9. **日报**
   玩家每回合首次进入休息室时，可查看日报，观看后续的发展历程。
   ·点击日报，可查看相关后续剧情发展
10. **升级**
    休息室中是可以对列车进行升级，解锁更多的申请人和席位
    ·点击“资源管理”按钮，打开管理界面，消耗磁带进行升级
11. **下一回合**
    玩家在休息室中处理完毕后，可以进行下一回合。
    ·点击“下一回合”按钮，进入下一回合
